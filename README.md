# 管行的个人作品集

纯静态个人网站，展示低空经济、星门纪元、时空胶囊和贪吃蛇。无需安装依赖，页面内容和交互支持离线打开；Neural 动态背景使用外部视频，需要联网。

## 查看网站

双击 `index.html`。也可以在此目录运行：

```sh
python3 -m http.server 5188 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:5188`。

## 添加图片

把图片放到 `images` 文件夹，使用以下文件名。支持 `.webp`、`.jpg`、`.png`、`.jpeg`，按此顺序尝试。无图片时会保留当前设计的封面占位，不会出现破图。

| 文件名（以 jpg 为例） | 用途 | 建议尺寸 |
| --- | --- | --- |
| `lowair-cover.jpg` | 低空经济封面及详情 | 1500 × 1000 |
| `stargate-cover.jpg` | 星门纪元封面及详情 | 1500 × 1000 |
| `capsule-cover.jpg` | 时空胶囊封面及详情 | 1500 × 1000 |
| `snake-cover.jpg` | 贪吃蛇封面及详情 | 1500 × 1000 |
| `portrait.jpg` | 关于我的个人照片 | 900 × 1100 |

图片使用居中裁切，主体尽量放在中间。放入图片后刷新网页即可；只需要替换文件，不需要修改代码。项目卡片与详情弹窗自动共用图片。

想先试试看效果，可以打开 `http://127.0.0.1:5188/?edit=1`，页脚会出现「管理图片」。在弹窗里选图即可预览；预览不会自动写入文件，正式保留仍需将图片放入 `images` 文件夹。

## 修改文字

- `index.html`：姓名、年龄、学校、首页介绍及卡片摘要。
- `script.js` 顶部 `projects`：四个作品的详细介绍。
- `styles.css` 顶部 `:root`：全站颜色。

年龄与学校信息已从同步副本移除。页面没有填写或虚构联系方式。

## 已实现

作品类型筛选、项目详情弹窗、手机导航、键盘操作、滚动进入动画、减少动态效果偏好适配，以及可玩贪吃蛇（方向键/WASD/触控、暂停、重开、碰撞、得分与加速）。

贪吃蛇为本作品集重新制作的展示版，未改动原来的小游戏目录。页面代码均在本目录，发布时无需引用电脑上的其他项目。

## 动态背景

背景沿用本目录 `neural.html` 的原始视频和海报地址，作为固定全屏背景，并叠加深色遮罩。视频静音循环，在切换到后台或打开弹窗时暂停；系统开启「减少动态效果」或视频不可用时回退到静态深色背景。`neural.html` 原文件未改动。
